## Where do you enter a Kohl's coupon code online?

Kohl's coupon codes are entered in the cart, not at the payment step. Add your items, open MY CART, and tap the link near the top labeled "APPLY COUPONS & KOHL'S CASH." A popup opens with an "ENTER CODE" field — type or paste the code there and apply it before proceeding to checkout.

Two things trip people up here:

1. **Codes are one-per-customer.** EXTRA20 and YOUSAVE20 both carry that restriction, and Kohl's enforces it against your account, not your browser. If a code fails with "already used," that's why.

## How Kohl's coupon stacking actually works

Kohl's applies dollar-off amounts before percentage discounts, in that order, and you can't combine two percent-off coupons. That official rule — "dollar-off coupons, including Kohl's Cash, will be applied prior to percent-off total purchase coupons" — matters more than it sounds, because it changes what each code is worth.

Here's the practical version. Say your cart is $150 and you have EXTRA20 ($20 off $100) and a 20% percent-off code. You can't use both percent-off codes together, but the system takes the $20 off first, then applies the percentage to the reduced subtotal where applicable. Conversely, if you stack a dollar-off code against Kohl's Cash, the Kohl's Cash gets consumed before the percent-off code touches the total — which can leave your percentage code doing less work than you expected.

The tier system behind the codes is the other thing generic coupon posts gloss over. Kohl's writes its best percentage codes for its members:

- **Everyone:** 15% off via first-time email signup; non-member codes typically hover around 15–20%
- **Kohl's Rewards members (free):** each purchase earns 5% back that converts into Kohl's Cash, plus access to member-exclusive codes like the 25% DDEAL, and birthday gifts
- **Kohl's Card holders:** rewards bump to 7.5%, a 40% discount code after opening the account, cardholder-exclusive coupons that historically run up to 30% off, and free shipping every month you spend $600+ on the card

That's why one aggregator's "30% off" headline rarely applies to a first-time shopper without a Kohl's Card. Read the code title, not just the number.
